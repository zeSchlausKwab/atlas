# Native viewer dependencies and attribution

The transport lab was copied from napplet-space commit
`d00ec1ea657c279c120de2c25f071298d17ecfdc`. Its MIT license and copyright notice are
retained in [LICENSE](LICENSE); no repository history or private planning files
were imported. Atlas's own reader, Hashtree and renderer sources are reused from
this repository, rather than copied into the Android module.

Cargo.lock records the native dependency graph. Gradle wrapper scripts/JAR are
generated by Gradle and retain their Apache-2.0 notices.

Hashtree blob framing follows `@hashtree/fips-transport` 0.5.0 (MIT), the reference
used by the original shell integration. This demo implements framing in Rust;
it does not copy the shell's TypeScript client. Native discovery uses its own
explicit experimental profile, documented in the architecture guide.

The real map used for acceptance contains OpenStreetMap data, © OpenStreetMap
contributors, under ODbL. The viewer displays that attribution. Map data, exported
blobs and provider identities remain untracked; a different input dataset needs
its own appropriate attribution. The example is not a license to redistribute
third-party raster data without permission.
