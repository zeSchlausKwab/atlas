The demo is original integration code under the repository's license. Cargo.lock
records the exact transitive dependency graph; Gradle wrapper scripts/JAR are
generated by Gradle and retain their Apache-2.0 notices.

Hashtree blob framing follows `@hashtree/fips-transport` 0.5.0 (MIT), the same
reference used by this repository's `packages/runtime/src/fips/vendor` files.
This demo implements the framing in Rust; it does not copy the TypeScript client.
